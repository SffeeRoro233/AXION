## About

Axion is a simple, lightweight and open-source multitool.

It is designed to be fast, easy to use and highly customizable.

Axion currently supports Windows.

The Linux version is now finished and is currently undergoing final testing before its public release.

🐧 **Linux release expected in less than 2 hours.**

Axion is actively evolving, with new tools, platform support and interface improvements planned for future versions.

## Features

- Lightweight interface
- Quick tool launcher
- Simple navigation
- Multiple tool categories
- Easy to customize
- Open-source
- Windows support
- Linux version completed and currently in testing
- More platforms planned

## Installation

### Windows

1. Download the latest Windows version
2. Extract the ZIP file
3. Open the Axion folder
4. Run `Axion.bat`

### Linux

The Linux version is currently undergoing final testing.

🐧 **Public release expected in less than 2 hours.**

Once released:

1. Download the Linux version
2. Extract the ZIP file
3. Open a terminal inside the Axion folder
