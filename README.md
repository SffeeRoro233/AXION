# About

Axion is a simple, lightweight and open-source multitool.

It is designed to be fast, easy to use and highly customizable.

Axion currently supports:

- Windows 10
- Windows 11
- Linux *(tested on Omarchy, should work on most Linux distributions)*

A macOS edition is currently being tested.

A native Windows `.EXE` version is also planned.

Axion is continuously evolving with new tools, platform support, animations and interface improvements.

# 🚀 Windows v3.0.0 Highlights

Axion v3.0.0 is one of the biggest updates released for Axion so far.

This version significantly expands Axion with a new multi-page interface, system utilities, network utilities, improved navigation, a redesigned startup experience and several internal improvements.

Axion is no longer only a launcher for websites and applications.

It is becoming a complete lightweight Windows utility hub.
