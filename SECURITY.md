### Version History

- **v1.0** — Windows only
- **v1.5** — Windows only
- **v2.0** — Windows supported, first Linux testing started
- **v2.1** — Linux version added and currently undergoing testing
- **macOS** — Not supported yet on any Axion version

Windows is officially supported in Axion v2.1.

Linux support is included in v2.1 and is currently being tested before being marked as fully supported.

macOS support is planned for a future version.

Older versions may no longer receive regular updates or security fixes.
